# Formulário de Cadastro

Este é um projeto simples de um formulário de cadastro desenvolvido em HTML e CSS. 

## 📝 Descrição

O projeto consiste em uma página de formulário de cadastro onde os usuários podem inserir suas informações pessoais, como nome, sobrenome, e-mail, celular, senha e gênero. O layout é responsivo e estilizado utilizando CSS externo.

## 🚀 Como Usar

Siga as instruções abaixo para utilizar o projeto em seu ambiente local.

### Pré-requisitos

Antes de começar, você precisará ter o seguinte instalado no seu computador:

- Um navegador web (Google Chrome, Firefox, etc.)

### Instalação

1. Clone o repositório:
    ```bash
    git clone https://github.com/kethyoliver/Formul-rio-de-Cadastro.git
    ```

2. Navegue até o diretório do projeto:
    ```bash
    cd seu-repositorio
    ```

3. Abra o arquivo `index.html` em seu navegador:
    - No Windows: Clique duas vezes no arquivo `index.html`
    - No Mac/Linux: Execute o comando:
        ```bash
        open index.html
        ```
